codelang（中文别名：懂网 / dongwang）是一个 Windows 桌面划词解释工具——你在任何应用里按住 Alt 划选一个看不懂的词，鼠标旁瞬间弹出一段大白话解释。专门解决"翻译工具只翻字面、看不懂代码英文和互联网黑话的真实意思"这个痛点。1540 条人工撰写词条 / 3398 查询键 / 13 大类。

和有道翻译 / Google 翻译有什么区别？

翻译工具只翻字面，codelang 给你讲清这个词在中国互联网/技术语境里到底是个什么意思。

幂等 idempotent（看不懂） 想象电梯按钮——按一下还是按八下都只来一次。同一个动作做几次结果一样。互联网做支付接口必须做幂等。
对齐 align（意思全错） 想象军训教官喊"向左看齐"——大家原本朝不同方向立刻调成一条线。大厂里就是开个短会同步信息。

词条样例（让你看看风格）

全部 1540 条都是「比喻 + 真实场景 + 具体例句」三段式。

幂等
想象电梯按钮——你按一下电梯开始上来，你心急又连按八下，电梯还是只来一次。"幂等"就是这种性质：同一个动作做一次和做八次，结果完全一样。互联网公司做支付/下单接口必须设计成幂等的，不然你重复点就被重复扣款。
RLHF
想象训狗——你给它两个答案 A 和 B，告诉它"A 比 B 好"，狗逐渐学会偏好 A 这一类。RLHF 就是让人类标注员对 LLM 输出打"A 比 B 好"的偏好，再用强化学习把这种偏好教给模型。ChatGPT 出圈的关键技术。
抓手
想象搬一个奇形怪状的箱子——你得先找到能抓住的把手才搬得动。"抓手"就是推动一件大事的具体切入点。"找抓手"=找一个能下手干活的点。
MVCC
多版本并发控制——每行数据存好几个版本，读的人看自己开始时的快照，写的人在旁边新建一版。读不阻塞写、写不阻塞读。MySQL InnoDB 和 PostgreSQL 的默认隔离级别都靠它实现可重复读。
0day
还没被厂商修复的漏洞——攻击者已知、防守方还不知道，没有补丁可打。打中之前你完全没防备，安全圈最值钱的资源。常见于浏览器、操作系统内核、企业邮箱网关。
RSU
限制性股票单位——公司直接给你股票（不是期权），但按 vesting 时间表分批解锁。常见 4 年 vest、1 年 cliff（满 1 年才开始解锁第一批，没到一年走人就全没）。比期权稳，因为不用自己掏钱行权。
N+1
裁员标准补偿——每工作一年补一个月工资，多 1 个月代通知金。N=工作年数。如果直接走还有 2N。
班味
想象一个人下班回家衣服都还能闻到打工的味道——皱、僵、面无表情。形容被工作消磨后整个人的状态。同事说"你最近班味好重"=你状态有点萎。
Karpathy（人物）
Andrej Karpathy——前 OpenAI 创始成员、前特斯拉 AI 总监，YouTube 上"手搓 GPT/Transformer"系列教程让全球开发者学会写大模型，"vibe coding"这个词也是他在 2025 年 2 月发明的，描述完全靠对话让 AI 写代码的开发方式。

怎么安装（3 分钟跑起来）

方式 A：下载安装包（推荐零基础）

  1. 装 Python 3.10+（官网下载，务必勾选"Add Python to PATH"）
  2. 从 Releases 页 下载 codelang-0.1.3-setup.exe（约 4 MB）
  3. 双击运行向导，一路下一步（Windows 蓝色警告 → "更多信息 → 仍要运行"）
  4. 勾选"立即启动" → 完成。右下角任务栏出现灰白色 UFO 小图标

方式 B：让 AI 帮你装

如果你电脑上有 Claude Code / Cursor / Windsurf / Codex CLI / 通义灵码任何一个 agentic AI，直接发：

装完直接帮我跑起来。

方式 C：手动源码

git clone https://github.com/XiaoChu-1208/codelang.git
cd codelang

怎么用

  • Alt + 双击词：最快——按住 Alt 不放在词上双击
  • Alt + 划词：选短语/多词——按住 Alt 拖拽
  • Alt + Q（v0.1.3 新增）：全局输入框——PDF 选不动 / 图片里的字 / 纸上的词 都能查
  • 终端窗口：Alt+划词自动走 UI Automation，无感修复
  • 按 Esc 或点窗外关闭卡片

常见问题（FAQ）

使用 codelang 之前你可能想知道的事情。

会有隐私问题吗？我看的内容会传到哪里？

完全本地。词库是离线 JSON 文件，查询全在你电脑内存里完成，零网络请求。除非你主动开启"AI 兜底"（默认关），才会把没收录的词单独发给 AI 解释——这个功能 100% 可选。词库更新检查也默认静默，不传任何隐私（可在 config.json 关闭）。

要联网才能用吗？

不要。断网状态下完全可以用，词库都在本地。

响应有多快？

本地命中 ~80 毫秒（含按 Alt → 取词 → 弹卡片 → 显示），体感是"瞬间"。词库全部加载到内存，O(1) 哈希查询。

支持 Mac / Linux 吗？

目前只有 Windows 版（依赖 Win32 API 取剪贴板和监听全局热键）。Mac/Linux 版在规划中，欢迎贡献。备用方案：浏览器扩展可在 Chrome/Edge/Firefox 上使用（限网页内）。

PDF 选不动文字、图片里的字怎么查？

用 Alt + Q（v0.1.3 新增）。任何应用里按 Alt + Q，鼠标旁弹一个小输入框，敲几个字母回车直接查。PDF 选不动文字、图片里的字、纸上看到的词——所有取不到的场景都能用。

终端（PowerShell / cmd）里 Alt+划词不工作？

v0.1.3 已修复。Windows Terminal / cmd / PowerShell 里 Alt+drag 被系统占用做"块选择"，所以标准划词不工作，codelang 自动走 UI Automation 读选区——跟普通应用体验一样无感。仍取不到时可用 Alt+Q 输入框兜底。

和浏览器划词翻译比有什么优势？

浏览器划词翻译只在浏览器里有效，codelang 在任何窗口都能用（Cursor、Claude 桌面端、PDF 阅读器、微信、Office、终端、IDE 全覆盖）。而且我们不是翻译，是用比喻和场景化语言解释概念。

词条解释是 AI 写的吗？

所有词条都是人工撰写的大白话风格，不是 AI 直接生成的产物（虽然 Claude 帮忙起草，但每条都过了人工调校确保通俗易懂）。

打错字也能查到吗？

能。v3 新增模糊匹配——输入 claud 自动定位 Claude，pyrhon 自动定位 Python，figmaa 自动定位 Figma。仅在精确未命中时启用，单字符编辑距离，仅英文且输入 ≥ 4 字符（不会把 pip 当 zip 的笔误）。卡片头部标注"你是不是想查 X？"让你知道这是猜的。

能贡献新词吗？怎么加自己的词？

三种方式：1) 卡片弹"未收录"时点「我录入这个词」按钮，存到 ~/.codelang/user_dict.yaml，远程更新不会覆盖；2) 改 dict/*.yaml 任何一个文件，托盘菜单点"重新加载词典"立即生效；3) 提 Pull Request 到 GitHub。

付费吗？可以商用吗？

100% 免费、开源、MIT 协议。可商用、可改、可分发，无任何限制。

不会编程能用吗？不会英文能用吗？

能。这正是 codelang 存在的理由——所有解释都用大白话 + 生活比喻，不需要懂任何编程或英文。产品经理、运营、设计师、HR、家属、记者、内容创作者都能用。
