一句话介绍

codelang（中文别名：懂网 / dongwang）是一个 Windows 桌面划词解释工具——你在任何应用里按住 Alt 划选一个看不懂的词，鼠标旁瞬间弹出一段大白话解释。专门解决"翻译工具只翻字面、看不懂代码英文和互联网黑话的真实意思"这个痛点。

大白话 + 故事

不是"应用程序编程接口"，而是"想象去快餐店点单，菜单就是 API"。每条都是「比喻 + 真实场景 + 具体例句」三段式。

100% 本地

词库是离线 JSON 文件，零网络请求，无隐私泄露。可选 LLM 兜底（默认关）走你自己的 API。

全局可用

浏览器、微信、Word、PDF、Cursor、Claude 桌面端、Notion —— 任何能选中文字的 Windows 应用都行。

瞬间响应

本地命中 ~80 毫秒（按 Alt → 取词 → 弹卡片）。多显示器、高 DPI 自适应。

和有道翻译 / Google 翻译有什么区别？

翻译工具只翻字面，codelang 给你讲清这个词在中国互联网/技术语境里到底是个什么意思。

你选中的词有道/Google 给的codelang 给的
幂等 idempotent（看不懂） 想象电梯按钮——按一下还是按八下都只来一次。同一个动作做几次结果一样。互联网做支付接口必须做幂等。
对齐 align（意思全错） 想象军训教官喊"向左看齐"——大家原本朝不同方向立刻调成一条线。大厂里就是开个短会同步信息。
Transformer 变压器（哈哈） 2017 年 Google 一篇论文提出的神经网络架构，当代所有大模型（GPT/Claude）底层都是 Transformer。
缓存击穿 cache breakdown（什么？） 网红奶茶店今日特供撤了那一秒所有人涌进店里围爆店员。代码里热门 key 突然过期，瞬间所有请求挤爆数据库。
班味 （查不到） 想象一个人下班回家衣服都还能闻到打工的味道——皱、僵、面无表情。

词条样例（让你看看风格）

全部 1088 条都是「比喻 + 真实场景 + 具体例句」三段式。

幂等
想象电梯按钮——你按一下电梯开始上来，你心急又连按八下，电梯还是只来一次。"幂等"就是这种性质：同一个动作做一次和做八次，结果完全一样。互联网公司做支付/下单接口必须设计成幂等的，不然你重复点就被重复扣款。
RLHF
想象训狗——你给它两个答案 A 和 B，告诉它"A 比 B 好"，狗逐渐学会偏好 A 这一类。RLHF 就是让人类标注员对 LLM 输出打"A 比 B 好"的偏好，再用强化学习把这种偏好教给模型。ChatGPT 出圈的关键技术。
抓手
想象搬一个奇形怪状的箱子——你得先找到能抓住的把手才搬得动。"抓手"就是推动一件大事的具体切入点。"找抓手"=找一个能下手干活的点。
N+1
裁员标准补偿——每工作一年补一个月工资，多 1 个月代通知金。N=工作年数。如果直接走还有 2N。
CSDN
中文最老牌的程序员技术博客和论坛——2000 年成立。文章质量参差，但搜中文技术问题答案几乎绕不开它。

手动装

需要 Python 3.10+（官网下载，记得勾"Add to PATH"）。

git clone https://github.com/XiaoChu-1208/codelang.git
cd codelang
py -m pip install -r requirements.txt
.\install.bat

双击桌面 codelang.lnk 启动，或在任意命令行里敲 codelang / dongwang。

用法

在任何 Windows 窗口里，按住 Alt + 鼠标在词上 双击 或 划选 即可触发。

常见问题（FAQ）

使用 codelang 之前你可能想知道的事情。

会有隐私问题吗？我看的内容会传到哪里？

完全本地。词库是离线 JSON 文件，查询全在你电脑内存里完成，零网络请求。除非你主动开启"AI 兜底"（默认关），才会把没收录的词单独发给 AI 解释——这个功能 100% 可选。

要联网才能用吗？

不要。断网状态下完全可以用，词库都在本地。

响应有多快？

本地命中 ~80 毫秒（含按 Alt → 取词 → 弹卡片 → 显示），体感是"瞬间"。

支持 Mac / Linux 吗？

目前只有 Windows 版（依赖 Win32 API 取剪贴板和监听全局热键）。Mac/Linux 版在规划中，欢迎贡献。备用方案：浏览器扩展可在 Chrome/Edge/Firefox 上使用（限网页内）。

和浏览器划词翻译比有什么优势？

浏览器划词翻译只在浏览器里有效，codelang 在任何窗口都能用（Cursor、Claude 桌面端、PDF 阅读器、微信、Office 全覆盖）。而且我们不是翻译，是用比喻和场景化语言解释概念。

词条解释是 AI 写的吗？

所有词条都是人工撰写的大白话风格，不是 AI 直接生成的产物（虽然 Claude 帮忙起草，但每条都过了人工调校确保通俗易懂）。

能贡献新词吗？

欢迎！直接提 Pull Request 修改 dict/*.yaml 文件即可，格式参考已有词条。也可以提 Issue 说"我希望加 XXX 词"。

付费吗？可以商用吗？

100% 免费、开源、MIT 协议。可商用、可改、可分发，无任何限制。

不会编程能用吗？不会英文能用吗？

能。这正是 codelang 存在的理由——所有解释都用大白话 + 生活比喻，不需要懂任何编程或英文。产品经理、运营、设计师、HR、家属都能用。

怎么加自己的词？

卡片弹出"未收录"时点「我录入这个词」按钮，输入含义保存，下次同样的词直接命中。不用懂代码、不用碰文件。或者直接编辑 dict/*.yaml 任何一个文件，托盘菜单点「重新加载词典」立即生效。
